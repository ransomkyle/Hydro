# Pilot plan (4 weeks)

**Goal:** prove the app on real shipments without risking a single one, and find the problems while they are cheap.

## Scope
- 1 plant first (Hiawatha), 3–5 named users per role, then add Lisbon.
- Run **in parallel with the current paper process** for weeks 1–2. Paper stays the record of truth until the exit review.
- Pick real shipments that cover the range: at least 3 small-parts, 3 standard, 2 sanitary, 1 pressure, **1 oversize (30 ft+)**.

## Weekly plan
| Week | Focus | Done when |
|---|---|---|
| 0 | Go-live checklist §1–4 complete; training | Everyone can sign in, set a PIN and sign one practice item |
| 1 | Operators/packers + inspectors use it beside paper | 10 shipments through the app, paper alongside |
| 2 | Shipping/logistics + pickup events, labels, photos, offline test (walk to a dead spot) | 5 pickups with driver signatures and GPS |
| 3 | QC manager release via the app only for pilot shipments; first CAPA and gauge workflows; reports reviewed | Release package accepted by QC for every pilot shipment |
| 4 | Fix list; second plant; exit review | Exit criteria below |

## What to measure (all from the Reports page)
- Time to release (median) vs. last month’s paper process.
- First-pass release %, item failure rate, flags by checklist section (tells you which checklist items are unclear or too strict).
- Any shipment left the dock without release (target: **0**).
- Offline entries (Audit page → “Offline only”) — did every one sync?

## Daily 10-minute huddle (QC manager + one dock lead)
Three questions: What confused people? What took too long? Did anything not match paper? Log every answer in the issue list (spreadsheet is fine): date, who, what happened, shipment #, severity.

## Exit criteria (all must be true)
1. Zero shipments left without a QC release.
2. Every pilot shipment’s PDF package matches the paper record on who/what/when (spot-check 100%).
3. No data loss; a restore test passed in the last 7 days.
4. Median time to release is no worse than paper.
5. Every user can sign off with PIN and complete an offline sign-off that synced.
6. Open issue list has no “blocker” severity items; checklist wording fixes applied and templates re-approved.
7. QC manager and plant manager sign the exit review (names/dates): ____________________

## Rollback
If the app is unavailable: continue on paper (keep blank forms printed at the dock). Enter the shipment afterward with its real dates in the note field; do not back-date sign-offs. The audit trail is not edited — late entries are visible as late.
